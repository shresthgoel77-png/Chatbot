# Chatbot
This is a full hardcoded chatbot built entirely using python using huggingface transformers and pytorch 
This chatbot uses :-
1- From hugging face an automodelforcasuallm which can predict certain conversations and finish them according to that
2- Auto tokenizer 
3- pytorch which is used to handling the tensors and neural network computations
4- warnings which can hide the unecessary warnings
